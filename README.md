# RÖDMARK

Raketen har kraschat på en främmande skogsplanet med röd jord, sjöar och luft man inte kan andas. Fäll träd, bryt malm,
bygg ugnar, borrar, band och gripare, och bygg fabriken som tar dig hemåt. Spela själv eller 1–4 i hemnätet.

## Ladda ner
Gå till **Releases** (högerspalten), ladda ner `RODMARK-<version>-win64.zip`, packa upp mappen var som helst
och starta `RODMARK.bat`. Spelet kollar efter uppdateringar vid varje start och hämtar bara de filer som ändrats.
Versionen står bredvid namnet i huvudmenyn.

Första gången kan Windows fråga om brandväggen: tillåt **privata nätverk**, annars hittar ni inte varandra.

## Spela ihop
Värden trycker **VAR VÄRD I HEMNÄTET** (IP-adressen står på knappen). De andra ser spelet under **SPEL I HEMNÄTET**,
eller skriver värdens IP i rutan **Värdens IP** och trycker **GÅ MED**. Alla måste vara i samma hemnät och ha samma
version (starta via `RODMARK.bat`, så blir det så). Skriv samma namn varje gång, så får du tillbaka ditt förråd.
